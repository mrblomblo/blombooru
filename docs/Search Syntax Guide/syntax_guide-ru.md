## Базовые теги

- `tag1 tag2`: Найти медиафайлы с обоими тегами
- `-tag1`: Исключить медиафайлы с тегом
- `tag*`: Wildcard-поиск
- `?tag`: Нечеткий поиск (один или ноль символов перед)
- `"tag with spaces"`: теги в кавычках или фразы с пробелами

## Диапазоны и оператора

Операторы: `:`, `..`, `>=`, `>`, `<=`, `<`, `!=`, `-`

- `id:100`: Точное совпадение
- `id:100..200`: Между (включительно)
- `id:..100`, `id:100..`: Диапазоны с открытым началом/концом
- `id:>=100`, `id:>100`, `id:<=100`, `id:<100`, `id:!=100`
- `id:1,2,3`: Из списка
- `gentags:13,16,<8,>91`: Множественный список
- `gentags:6,4 gentags:8,>4`: Автоматически комбинировать и упрощать диапазоны (например, 1-3,5,7-9) (`gentags:>=4`)
- `gentags:5,6,<=15`: Поглощённые значения автоматически очищаются (`gentags:<=15`)
- `-rating:e`, `-parent:none`: Анулировать любой квалификатор с префиксом "-"

Примечание: Диапазоны также могут использоваться с большинством мета-качеств

## Мета-качества (например, рейтинг или наличие ссылки на источник)

### Связи и иерархия

- `parent`: ID родительского поста (`parent:none` для поиска исключительно родительских постов, `parent:any` для дочерних постов, `parent:100` для поиска дочерних постов от родительского поста с ID=100)
- `child`: ID дочернего поста (`child:none` для поиска постов без дочерних, `child:any` для поиска родительских постов, `child:200` для точного совпадения)
- `id`: Внутренний ID медиафайла (`id:100`, `id:1..50`)

### Альбомы и пулы

- `album` / `pool`: ID / название альбома или пула (`album:none` для неназначенных, `album:any` (в любом альбоме), `album:favorites` (поиск постов, находящихся в альбоме "favorites"), `pool:5`)
- `album_tree` / `pool_tree`: Рекурсивный поиск по альбому / пулу, (включающий все вложенные подальбомы) (`album_tree:artbook`, `pool_tree:1`)

### Свойства медиафайла

- `width`, `height`: Размеры изображения в пикселях (`width:>=1920`, `height:<1080`)
- `duration`: Длительность видео / GIF в секундах (`duration:>30`, `duration:10..60`)
- `filesize`: Вес файла (b, kb, mb, gb, поддерживает нечёткие совпадения) (`filesize:>5mb`, `filesize:52mb`)
- `filetype`: Расширение (png, gif, mp4, итд.) или тип медиа (image, video) (`filetype:png,jpg`, `filetype:video`)

### Метаданные и информация

- `rating`: safe, questionable, explicit (s, q, e) (`rating:s,q`, `-rating:e`)
- `source`: URL источника, домена, http или пустой (`source:twitter`, `source:none`, `source:http`)
- `date`, `age`: Дата загрузки (ГГГГ-ММ-ДД) или относительный возраст (s, mi, h, d, w, mo, y) (`date:>=2024-01-01`, `age:<24h`, `age:1w..1mo`)
- `custom_date`, `custom_age`: Пользовательская дата медиафайла (ГГГГ-ММ-ДД) или пользовательский относительный возраст (s, mi, h, d, w, mo, y) (`custom_date:>=2024-01-01`, `custom_age:<30d`, `custom_date:2024-01-01..2024-12-31`)
- `md5`: Точная контрольная сумма MD5 (`md5:d34e...`)

### Подсчет тегов

- `tagcount`, `gentags`, `chartags`...: Общее количество тегов
- `gentags`, `arttags`, `chartags`, `copytags`, `metatags`: Подсчет тегов в указанной категории

## Сортировка

Используйте `order:значение`. Поддерживаются суффиксы `_asc` or `_desc`. Большинство сортируется по снижению, но filename, rating, и md5 по умолчанию сортируются по возрастанию.

- `id` / `id_desc`: Сначала новые (по умолчанию)
- `id_asc`: Сначала старые
- `date_desc` / `date_asc`: Дате медиафайла
- `custom_date_desc` / `custom_date_asc`: Пользовательская дата медиафайла
- `filesize` / `filesize_asc`: Размер файла
- `width_desc` / `height_desc` / `mpixels_desc`: Разрешение файла
- `duration_desc` / `duration_asc`: Длительность (для видео и GIF)
- `landscape` / `portrait`: Соотношение сторон (16:9 / 9:16)
- `rating_asc` / `rating_desc`: По порядку рейтинга (safe, questionable, explicit)
- `filename_asc` / `filename_desc`: Оригинальное имя файла (по алфавиту)
- `filetype_desc` / `filetype_asc`: Формат / расширение файла
- `md5_asc` / `md5_desc`: Контрольная сумма MD5 
- `tagcount_desc` / `tagcount_asc`: Общее количество тегов
- `gentags_desc`, `arttags_desc`, `chartags_desc`...: Количество тегов в категории
- `random` / `random:<seed>`: Случайный порядок
- `custom`: Выдача в том же порядке, в котором введены ID (пример: `id:5,2,8 order:custom`)

## Примеры поиска

- `cat source:none rating:s`: Изображения с котами, рейтинга Safe без источника
- `landscape filetype:mp4 filesize:>5mb`: Альбомные видео высокого качества
- `parent:none child:any`: Корневые посты с или без дочерних постов
- `album_tree:artbook order:id_asc`: Рекурсивный поиск внутри альбома, сначала самые старые посты
- `id:1..100 order:id_asc`: Первые 100 загрузок, сначала более ранние
- `order:random:42 rating:s`: Рандомная выдача постов с рейтингом safe с неслучайным seed
- `?girl? *_eyes -dog`: Поиск 1+ девушек с любым цветом глаз, без собак
- `tagcount:>20 arttags:0`: Посты с количеством тегов 20+, но без информации об артисте
